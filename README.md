## 🚀 Déploiement

Ce projet est déployé sur :
- **GitHub** : [https://github.com/D4rkCrypte/Ter_Sec_1](https://github.com/D4rkCrypte/Ter_Sec_1)

## 🔄 Mise à jour

Pour mettre à jour le site sur Netlify :

1. Faire des modifications dans le code
2. Commiter les changements :
   ```bash
   git add .
   git commit -m "Description des modifications"
   git push
   ```
3. Netlify déploiera automatiquement les changements
