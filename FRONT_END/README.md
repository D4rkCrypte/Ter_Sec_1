# TERANGA SECURITY - Clone du Site Web

Ce projet est un clone complet du site web TERANGA SECURITY (https://teranga-security.netlify.app/).

## 📋 Description

Plateforme sénégalaise de formation et sensibilisation en cybersécurité. Le site offre des formations, des ressources et un accompagnement pour les jeunes Sénégalais dans le domaine de la cybersécurité.

## 🚀 Fonctionnalités

- **Design moderne et responsive** : Compatible avec tous les appareils (desktop, tablette, mobile)
- **Navigation fluide** : Menu de navigation sticky avec scroll smooth
- **Sections complètes** :
  - Hero section avec call-to-action
  - Notre mission
  - Nos Piliers (Formation, Sensibilisation, Protection)
  - Pourquoi nous choisir
  - Témoignages
  - Communauté Sénégalaise avec statistiques
  - Footer complet avec liens et contact

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Styles modernes avec CSS Grid, Flexbox, animations
- **JavaScript (Vanilla)** : Interactivité, animations au scroll, menu mobile

## 🚀 Installation et Utilisation

### Option 1 : Ouvrir directement dans le navigateur

1. Téléchargez ou clonez ce projet
2. Ouvrez le fichier `index.html` dans votre navigateur web

### Option 2 : Utiliser un serveur local

#### Avec Python :
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Avec Node.js (http-server) :
```bash
npx http-server
```

#### Avec PHP :
```bash
php -S localhost:8000
```

Ensuite, ouvrez votre navigateur et allez à `http://localhost:8000`
